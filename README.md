Code and Data

Code and data associated with A Century of Sea-Level Change in Ireland (1925–2024).    

Reproducibility note: The analysis uses a fixed random seed to support reproducibility. 
However, results reproduced on different computers or software environments may differ slightly 
from the published results because of differences in R, package and JAGS versions, numerical calculations, 
or sampling behaviour. Small differences in posterior estimates and credible intervals may therefore occur. 
Users should record their software versions and assess model convergence when reproducing the analysis.

GitHub repository: contains the analysis code, input datasets, and supporting RESLR files.
Additional code: Other code associated with the paper may be requested from the author at patrick.mcloughlin.2014@mumail.ie.
